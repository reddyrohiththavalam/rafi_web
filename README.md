# D. Mohammad Rafi — Portfolio

Personal portfolio for D. Mohammad Rafi, an Electronics and Communication Engineering student, video editor, visual artist, and digital content creator.

**Live website:** [d-mohammad-rafi.netlify.app](https://d-mohammad-rafi.netlify.app/)

## About the project

A responsive portfolio showcasing Rafi’s creative work, photo compositions, video edits, technical interests, and contact details.

## Project structure

The website files and media are in [`my_website/`](./my_website/):

- `index.html` — page content and metadata
- `styles.css` — responsive styling
- `script.js` — video player, audio toggle, navigation, and contact form
- JPEG files — portrait and photo artwork
- MP4 files — video portfolio clips with their original audio

## Run locally

For reliable video playback, serve the site over HTTP rather than opening the HTML file directly.

With Python installed:

```powershell
cd my_website
python -m http.server 8000
